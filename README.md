# Terrain Search Assistant

Локальное приложение поддержки поисковой группы при разборе видеозаписей с дрона.

**Средство поддержки оператора.** Приложение не делает вывод «людей нет» и не объявляет участок безопасным. Видео, телеметрия и кадры не отправляются во внешние сервисы.

## Назначение

- контролируемый покадровый просмотр больших локальных MP4/MOV/MKV;
- DJI SRT-телеметрия (если есть) — маршрут и ориентировочный визир;
- секторы поиска и площадь объединения без двойного учёта пересечений;
- фиксация качества просмотра и всех сомнительных кандидатов;
- опциональная YOLO-подсказка на кадре (не автоматическое решение);
- воспроизводимый журнал проверки в SQLite.

## Границы текущей версии

**Реализовано:** импорт по пути каталога, ffprobe, парсер DJI SRT (в т.ч. отдельная привязка), операции/секторы, Folium-карта, маршрут и визир, площади, покадровая инспекция, сетки 2×3/3×3, фильтры, сессии и усталость, кандидаты, SQLite, опциональный YOLO, упрощённый UI инспекции.

**Не реализовано:** DEM / ray–terrain, 2.5D/3D, фотограмметрия, точная координата объекта, face recognition, облако, мультипользовательская авторизация, непрерывное воспроизведение ≤0.5×.

У части роликов **нет SRT** — это нормально: инспекция работает, трек и координаты дрона просто недоступны.

## Архитектура

`src` layout. Бизнес-логика вне Streamlit UI.

| Пакет | Ответственность |
|-------|-----------------|
| `domain` | модели и enum |
| `telemetry` | DJI SRT, трек |
| `video` | discovery, ffprobe, кадры, фильтры |
| `geo` | площади, визир, секторы, заготовки DEM |
| `review` | сессии, прогресс, кандидаты |
| `storage` | SQLite + repositories |
| `vision` | `Detector`, `NullDetector`, YOLO |
| `ui` | тонкие Streamlit-views |

## Требования

| Компонент | Минимум |
|-----------|---------|
| ОС | Windows 10/11, macOS 12+, Linux (Ubuntu 22.04+ / аналог) |
| Python | **3.12** |
| Менеджер пакетов | [uv](https://docs.astral.sh/uv/) |
| FFmpeg | `ffmpeg` и `ffprobe` в `PATH` |
| Диск | запас под видео (исходники не копируются) + `data/`, при YOLO — `models/` (~10–200+ МБ весов) |
| GPU | не обязателен (YOLO по умолчанию на CPU) |

Рекомендуется ≥16 ГБ RAM при работе с 4K-роликами и YOLO.

## Установка по платформам

### 1. Общий порядок

1. Установить Python 3.12 (если ещё нет).
2. Установить `uv`.
3. Установить FFmpeg.
4. Клонировать/открыть репозиторий.
5. `uv sync` (и при необходимости `uv sync --extra yolo`).
6. Запуск Streamlit.

### 2. macOS

**Python 3.12** (Homebrew):

```bash
brew install python@3.12
```

**uv:**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
# затем переоткройте терминал или:
source "$HOME/.local/bin/env"
```

**FFmpeg:**

```bash
brew install ffmpeg
ffprobe -version
```

**Проект:**

```bash
cd terrain-search-assistant
uv sync
uv run streamlit run src/terrain_search_assistant/app.py
```

**Рекомендации macOS**

- Для Apple Silicon (`arm64`) используйте нативный Python/Homebrew — не Rosetta без необходимости.
- Пути к видео с пробелами и кириллицей допустимы; указывайте полный путь в поле каталога.
- При первом запуске YOLO веса кладите в `models/yolov8n.pt` или разрешите загрузку один раз в UI.
- Gatekeeper может спросить разрешение на сеть только если вы явно скачиваете веса; сам разбор видео офлайн.

### 3. Linux (Debian / Ubuntu и аналоги)

**Системные пакеты:**

```bash
sudo apt update
sudo apt install -y curl ffmpeg
# при необходимости:
sudo apt install -y python3.12 python3.12-venv
```

**uv:**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source "$HOME/.local/bin/env"
```

**Проект:**

```bash
cd terrain-search-assistant
uv sync
uv run streamlit run src/terrain_search_assistant/app.py
```

**Fedora:**

```bash
sudo dnf install ffmpeg
```

**Arch:**

```bash
sudo pacman -S ffmpeg
```

**Рекомендации Linux**

- Убедитесь, что `ffprobe` в `PATH`: `which ffprobe`.
- На headless-сервере UI всё равно открывается в браузере по `http://localhost:8501` (или через SSH-туннель).
- Для YOLO на CPU достаточно; CUDA нужна только если сознательно меняете `yolo_device` в конфиге и ставите GPU-сборку PyTorch (не входит в базовый сценарий).
- SELinux/AppArmor обычно не мешают локальному чтению файлов, если каталог видео доступен пользователю.

### 4. Windows 10 / 11

**Вариант A — рекомендуемый (winget + PowerShell)**

1. Установите Python 3.12:

```powershell
winget install Python.Python.3.12
```

2. Установите FFmpeg:

```powershell
winget install Gyan.FFmpeg
```

Либо скачайте сборку с [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html) и добавьте папку `bin` в **PATH** (Параметры → Система → О программе → Доп. параметры → Переменные среды).

3. Установите `uv`:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Переоткройте PowerShell / Windows Terminal.

4. Проверка:

```powershell
python --version
uv --version
ffprobe -version
```

5. Проект:

```powershell
cd path\to\terrain-search-assistant
uv sync
uv run streamlit run src/terrain_search_assistant/app.py
```

Браузер откроет `http://localhost:8501`.

**Вариант B — Windows + WSL2 (Ubuntu)**

Если удобнее Linux-окружение:

```powershell
wsl --install
```

Далее внутри WSL повторите шаги раздела Linux. Видео с диска Windows доступны как `/mnt/c/...` — указывайте этот путь в приложении.

**Рекомендации Windows**

- Используйте **Windows Terminal** или PowerShell 7, не устаревший cmd.
- Пути лучше с прямыми слэшами или в кавычках: `D:/Search/Flight01` или `"D:\Search\Flight 01"`.
- Антивирус иногда тормозит первое чтение больших MP4 — добавьте каталог проекта и видео в исключения при необходимости.
- После установки FFmpeg **обязательно** новый терминал, иначе `ffprobe` «не найден».
- Для YOLO: `uv sync --extra yolo`, файл `models\yolov8n.pt`. Первый импорт PyTorch/ultralytics может занять несколько минут и сотни МБ диска.

## Установка зависимостей проекта

Базовая установка (без YOLO):

```bash
uv sync
```

С YOLO (опционально):

```bash
uv sync --extra yolo
```

Веса по умолчанию: `models/yolov8n.pt`.  
Можно положить файл вручную или один раз разрешить загрузку из UI. Автоскачивание без согласия оператора не выполняется.

Dev-инструменты (тесты/линтеры) уже в dependency group `dev` при `uv sync`.

## Запуск

```bash
uv run streamlit run src/terrain_search_assistant/app.py
```

Типичный URL: **http://localhost:8501**

Остановить: `Ctrl+C` в терминале.

### Быстрый сценарий оператора

1. **Операция** — создать/выбрать операцию.
2. **Видео** — указать локальный каталог → сканировать → выбрать ролик.
3. При наличии SRT — автосопоставление по имени или **привязка вручную** (имя может отличаться). Без SRT — просто продолжайте.
4. **Инспекция** — покадровый просмотр (крупный кадр слева, панель справа).
5. **Карта** — секторы; трек появится только если у активного видео есть SRT с GPS.
6. **Кандидаты** — журнал сомнительных объектов.

## Структура локальных данных

```text
data/
  terrain_search.db          # SQLite
  artifacts/
    screenshots/             # полные кадры кандидатов
    crops/                   # вырезки
models/
  yolov8n.pt                 # опционально, для YOLO
```

Исходные видео **не копируются** — в БД хранятся путь и метаданные.  
Каталоги `data/`, `models/`, `*.mp4`, `*.db` в `.gitignore`.

## DJI SRT

- Поддержка типичных DJI SRT (в т.ч. `<font>`, UTF-8/UTF-16, CRLF).
- Форматы GPS: `[latitude]/[longitude]` и `GPS(lat, lon[, alt])`.
- Отсутствие GPS в отдельных cue-блоках допустимо.
- SRT можно привязать к видео **отдельно** от имени файла.
- Нет SRT у ролика — штатная ситуация.

## YOLO (опционально)

- Адаптер через `Detector`; по умолчанию безопасный режим без модели.
- Пустой результат YOLO **≠** «людей нет».
- Кадры обрабатываются локально.
- Общий COCO `yolov8n` на снегу/с дрона слаб — это подсказка, не SAR-детектор.
- Device по умолчанию: `cpu` (`config.yolo_device`).

## Операторский протокол

- инспекция покадрово (в этой версии нет гарантированного ≤0.5× playback);
- сложный рельеф — покадрово;
- сетка 2×3 или 3×3;
- перерывы каждые 20–30 мин (40 мин — высокий риск усталости);
- плохие участки фиксируются так же, как чистые;
- сомнительные признаки сохраняются всегда;
- координаты дрона **не равны** координатам объекта;
- цвет ненадёжен; фильтры не восстанавливают утраченные детали;
- навигационный плеер Streamlit **не** считается подтверждённым просмотром.

## Статусы качества

`NOT_REVIEWED`, `REVIEWED_CLEAR`, `REVIEWED_POOR`, `REVIEW_REQUIRED`, `REVIEWED_WITH_CANDIDATES`, `REQUIRES_REFLIGHT`.

Проблемы: туман, смаз, пересвет/недосвет, слишком быстрая камера, низкое разрешение, окклюзия рельефа, трещины ледника, риск усталости и др.

## Фиксация кандидата

Обязательны: видео, frame index, таймкод, категория, ≥1 evidence tag, описание, confidence 1–5, флаг/причина reflight.

Автоматически (если есть в SRT): координаты дрона, высота, yaw/pitch/roll, focal length, zoom.

Подпись в UI: **«Координаты дрона из телеметрии»**.  
Отклонение меняет статус и пишет историю; запись не удаляется.

## Предупреждения о координатах

- визир ориентировочный; пересечение с рельефом не рассчитано;
- `relative_altitude` — не высота над DEM;
- точная координата объекта и footprint без DEM недоступны;
- площадь секторов считается геодезически (не `Shapely.area` в EPSG:4326).

## Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| `ffprobe not found` | FFmpeg установлен и новый терминал открыт; `ffprobe -version` |
| SRT «нет» | У ролика может не быть SRT; или привяжите путь вручную во вкладке «Видео» |
| Трек пустой | Нет SRT / нет GPS в SRT / выбрано другое видео |
| YOLO не стартует | `uv sync --extra yolo`, файл `models/yolov8n.pt` |
| Порт 8501 занят | Закройте другой Streamlit или укажите `--server.port 8510` |
| Windows: длинные пути | Включите long paths или перенесите проект ближе к корню диска |

## Roadmap

1. Кастомный видеокомпонент с ограничением скорости ≤0.5×.
2. Специализированные веса SAR / fine-tune под снег и дрон.
3. DEM + ray–terrain для визира и uncertainty.
4. Экспорт журнала операции (PDF/GeoJSON).

## Этика

Инструмент для поисковых групп. Ложные «все чисто» недопустимы: сомнения сохраняются, покрытие без DEM не заявляется, отсутствие детекций YOLO не интерпретируется как безопасность участка.
