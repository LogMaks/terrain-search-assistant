# Terrain Search Assistant

Локальное приложение поддержки поисковой группы при разборе видеозаписей с дрона.

**Средство поддержки оператора.** Приложение не делает вывод «людей нет» и не объявляет участок безопасным.

## Назначение

- просмотр больших локальных MP4 в контролируемом (покадровом) режиме;
- использование DJI SRT-телеметрии;
- маршрут дрона и ориентировочный визир камеры;
- секторы поиска и площадь объединения без двойного учёта пересечений;
- фиксация качества просмотра и всех сомнительных кандидатов;
- воспроизводимый журнал проверки в SQLite.

## Границы текущей версии (итерация 1)

Реализовано: импорт по пути каталога, ffprobe, парсер DJI SRT, операции/секторы, Folium-карта, маршрут и визир, площади, покадровая инспекция, сетки 2×3/3×3, фильтры, сессии и усталость, кандидаты, SQLite, тесты.

**Не реализовано:** нейродетектор, DEM/ray–terrain, 2.5D/3D, фотограмметрия, точная координата объекта, face recognition, облако, мультипользовательская авторизация, непрерывное воспроизведение ≤0.5×.

## Архитектура

`src` layout. Бизнес-логика вне Streamlit UI.

| Пакет | Ответственность |
|-------|-----------------|
| `domain` | модели и enum |
| `telemetry` | DJI SRT |
| `video` | discovery, ffprobe, кадры, фильтры |
| `geo` | площади, визир, секторы, заготовки DEM |
| `review` | сессии, прогресс, кандидаты |
| `storage` | SQLite + repositories |
| `vision` | `Detector` protocol + `NullDetector` |
| `ui` | тонкие Streamlit-views |

## Требования

- Python 3.12
- [uv](https://docs.astral.sh/uv/)
- FFmpeg / ffprobe в `PATH`
- macOS / Linux (локально)

## Установка

```bash
uv sync
```

### FFmpeg

```bash
# macOS
brew install ffmpeg

# Debian/Ubuntu
sudo apt install ffmpeg
```

Проверка: `ffprobe -version`

## Запуск

```bash
uv run streamlit run src/terrain_search_assistant/app.py
```

Данные остаются на машине оператора. Видео и телеметрия наружу не отправляются.

## Структура локальных данных

```text
data/
  terrain_search.db
  artifacts/
    screenshots/
    crops/
```

Исходные видео не копируются — хранятся только пути и метаданные.

## DJI SRT

Парсер поддерживает HTML-теги `<font>`, извлекает известные поля (GPS, высоты, gimbal, камера), игнорирует неизвестные, допускает отсутствие GPS, валидирует порядок времени и диапазоны координат, ограничивает размер файла.

## Операторский протокол

- инспекционный просмотр не быстрее 0.5× **либо покадрово** (в этой версии — только покадрово);
- сложный рельеф проверяется покадрово;
- кадр делится на 6 (2×3) или 9 (3×3) ячеек;
- перерывы рекомендуются каждые 20–30 минут (порог 40 мин — высокий риск усталости);
- плохие участки фиксируются так же, как чистые;
- сомнительные признаки сохраняются всегда;
- координаты дрона **не равны** координатам объекта;
- цвет ненадёжен;
- фильтры не восстанавливают утраченную информацию.

Навигационный плеер Streamlit служит только для быстрого перехода и **не** считается подтверждённым просмотром.

## Статусы качества

`NOT_REVIEWED`, `REVIEWED_CLEAR`, `REVIEWED_POOR`, `REVIEW_REQUIRED`, `REVIEWED_WITH_CANDIDATES`, `REQUIRES_REFLIGHT`.

Проблемы: туман, смаз, пересвет/недосвет, слишком быстрая камера, низкое разрешение, окклюзия рельефа, трещины ледника, риск усталости и др.

## Фиксация кандидата

Обязательны: видео, frame index, таймкод, категория, ≥1 evidence tag, описание, confidence 1–5, флаг/причина reflight.

Автоматически (если есть в SRT): координаты дрона, высота, yaw/pitch/roll, focal length, zoom.

Подпись в UI: **«Координаты дрона из телеметрии»**.

Отклонение кандидата меняет статус и пишет историю; запись не удаляется.

## Предупреждения о координатах

- визир ориентировочный; пересечение с рельефом не рассчитано;
- `relative_altitude` — не высота над DEM;
- точная координата объекта и footprint без DEM недоступны;
- площадь секторов считается геодезически (не `Shapely.area` в EPSG:4326).

## Тестирование

```bash
uv run ruff check .
uv run mypy src
uv run pytest -q
```

Тесты работают без сети, GPU, реального видео, весов и DEM.

## Roadmap (не начат автоматически)

1. Кастомный видеокомпонент с ограничением скорости ≤0.5×.
2. Адаптер детектора (без автовывода «пусто»).
3. DEM + ray–terrain intersection для визира и uncertainty.
4. Экспорт журнала операции (PDF/GeoJSON).

## Лицензия / этика

Инструмент для поисковых групп. Ложные «все чисто» недопустимы: сомнения сохраняются, покрытие без DEM не заявляется.
